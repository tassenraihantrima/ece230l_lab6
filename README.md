## Lab Summary

In this lab, we learned how binary addition works using logic gates. We used an XOR gate for the stairway light and built a one-bit adder using XOR for the sum and AND for the carry. We also used two full adders to make a two-bit adder and learned how the carry-out from one adder connects to the carry-in of the next adder.

## Lab Questions

### 1 - How might you add more than two bits together?

We can add more bits by connecting more full adders together. The carry-out from one full adder becomes the carry-in of the next full adder.

### 2 - What is the importance of the XOR gate in an adder?

The XOR gate is used to get the sum when adding two bits.

### 3 - What is the largest number a two bit adder can handle? What happens when you go over?

The largest result a two-bit adder can produce is 6, which is 110 in binary. When the result goes over what two sum bits can represent, the carry-out bit turns on.
